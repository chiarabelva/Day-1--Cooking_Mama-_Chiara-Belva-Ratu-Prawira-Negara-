## 📁 Deskripsi Repository
Repository ini merupakan tempat penyimpanan kode untuk aplikasi web sederhana bernama "Student Task Planner[span_0](start_span)"[span_0](end_span). Aplikasi ini dibangun dengan mengimplementasikan bantuan AI (Prompt Engineering) dan dikelola riwayat perubahannya menggunakan sistem *version control*[span_1](start_span)[span_1](end_span). 

## 🎯 Tujuan dan Kegunaan Repository
Tujuan utama repository ini adalah untuk mendokumentasikan hasil praktik dari workshop, melacak setiap perubahan kode secara lokal maupun *online*, serta menjadi wadah kolaborasi manajemen perubahan menggunakan perintah-perintah Git dan GitHub.

## 📝 Dokumentasi Kegiatan Workshop
Berikut adalah penjabaran dokumentasi kegiatan workshop hari ini:

### 1. Rangkuman Materi
Workshop yang dibawakan oleh Nugi Farhan ini mengangkat tema "Building with AI, Managing Change with GitHub[span_2](start_span)[span_3](start_span)"[span_2](end_span)[span_3](end_span). Materi terbagi menjadi dua fokus utama:
* **Prompt Engineering:** Instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu[span_4](start_span)[span_4](end_span). Struktur *prompt* yang baik dan komprehensif harus memuat empat elemen: *Role*, *Task*, *Context*, dan *Format*[span_5](start_span)[span_5](end_span). Memberikan konteks sangat penting agar aplikasi yang dibuat sesuai dengan kebutuhan dan standar[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span).
* **Manajemen Perubahan (Git & GitHub):** Pengenalan tentang Git sebagai sistem *version control* terdistribusi untuk melacak perubahan kode secara lokal, dan GitHub sebagai platform berbasis web untuk menyimpan repository secara *online* dan berkolaborasi[span_8](start_span)[span_8](end_span). Materi mencakup alur kerja Git dari *Working Directory*, masuk ke *Staging Area*, hingga disimpan di *Repository* (*.git directory*)[span_9](start_span)[span_9](end_span).

### 2. Poin-Poin Penting dan Pengetahuan Baru
* **Keuntungan Prompt Engineering:** Merancang *prompt* yang spesifik tidak hanya meningkatkan performa model AI, tetapi juga mengurangi bias, meningkatkan kontrol, dan memberikan hasil yang lebih dapat diprediksi[span_10](start_span)[span_10](end_span).
* **Perbedaan Git dan GitHub:** Git adalah alat (sistem) yang berjalan di komputer lokal kita, sedangkan GitHub adalah layanan *hosting* di internet untuk menyimpan repository Git tersebut[span_11](start_span)[span_11](end_span).
* **Perintah Dasar (Essential Commands):** Mempelajari penggunaan perintah fundamental seperti `git init` (memulai repo), `git add .` (memindahkan file ke *staging area*), `git commit -m` (menyimpan file ke repo), `git push`, dan `git pull`[span_12](start_span)[span_12](end_span)[span_13](start_span)[span_13](end_span).
* **Keamanan Akses:** Praktik menghubungkan komputer lokal ke GitHub secara aman menggunakan SSH Key (Ed25519) dan menambahkannya ke agen SSH serta GitHub[span_14](start_span)[span_14](end_span)[span_15](start_span)[span_15](end_span)[span_16](start_span)[span_16](end_span).
