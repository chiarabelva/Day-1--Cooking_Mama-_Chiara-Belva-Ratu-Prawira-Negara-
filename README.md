## 📁 Deskripsi Repository
Repository ini merupakan tempat penyimpanan kode untuk aplikasi web sederhana bernama "Student Task Planner". Aplikasi ini dibangun dengan mengimplementasikan bantuan AI (Prompt Engineering) dan dikelola riwayat perubahannya menggunakan sistem *version control*.

## 🎯 Tujuan dan Kegunaan Repository
Tujuan utama repository ini adalah untuk mendokumentasikan hasil praktik dari workshop, melacak setiap perubahan kode secara lokal maupun *online*, serta menjadi wadah kolaborasi manajemen perubahan menggunakan perintah-perintah Git dan GitHub.

---

## 📝 Dokumentasi Kegiatan Workshop
Berikut adalah penjabaran dokumentasi kegiatan workshop hari ini:

### 1. Rangkuman Materi
Workshop yang dibawakan oleh Nugi Farhan ini mengangkat tema "Building with AI, Managing Change with GitHub". Materi terbagi menjadi dua fokus utama:
* **Prompt Engineering:** Instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu. Struktur *prompt* yang baik dan komprehensif harus memuat empat elemen: *Role*, *Task*, *Context*, dan *Format*. Memberikan konteks sangat penting agar aplikasi yang dibuat sesuai dengan kebutuhan dan standar.
* **Manajemen Perubahan (Git & GitHub):** Pengenalan tentang Git sebagai sistem *version control* terdistribusi untuk melacak perubahan kode secara lokal, dan GitHub sebagai platform berbasis web untuk menyimpan repository secara *online* dan berkolaborasi. Materi mencakup alur kerja Git dari *Working Directory*, masuk ke *Staging Area*, hingga disimpan di *Repository* (*.git directory*).

### 2. Poin-Poin Penting dan Pengetahuan Baru
* **Keuntungan Prompt Engineering:** Merancang *prompt* yang spesifik tidak hanya meningkatkan performa model AI, tetapi juga mengurangi bias, meningkatkan kontrol, dan memberikan hasil yang lebih dapat diprediksi.
* **Perbedaan Git dan GitHub:** Git adalah alat (sistem) yang berjalan di komputer lokal kita, sedangkan GitHub adalah layanan *hosting* di internet untuk menyimpan repository Git tersebut.
* **Perintah Dasar (Essential Commands):** Mempelajari penggunaan perintah fundamental seperti `git init` (memulai repo), `git add .` (memindahkan file ke *staging area*), `git commit -m` (menyimpan file ke repo), `git push`, dan `git pull`.
* **Keamanan Akses:** Praktik menghubungkan komputer lokal ke GitHub secara aman menggunakan SSH Key (Ed25519) dan menambahkannya ke agen SSH serta GitHub.

## 📝 Rangkuman Materi

Workshop kali ini tidak hanya membahas teknis pengembangan kode, tetapi juga memberikan wawasan seputar kerangka penyelesaian masalah dan pengenalan program akademik. Berikut adalah gagasan utama yang disampaikan:

* **Pengenalan Profil dan Visi Prodi**
  Program Studi Teknik Multimedia Digital (TMD) memiliki cita-cita besar untuk diakui secara global, khususnya pada sektor pengembangan permainan digital, karya animasi, serta sajian multimedia interaktif guna mendongkrak keunggulan kompetitif negara. Untuk mencapai profil lulusan yang ideal ini, mahasiswa diarahkan untuk menyelesaikan beban studi secara total sebanyak 144 SKS yang dikemas ke dalam 55 mata kuliah.

* **Pilar Kompetensi Mahasiswa**
  Terdapat tiga fondasi utama yang wajib dikembangkan selama masa studi, yakni pemahaman wawasan keilmuan (*Knowledge*), pembentukan tata krama atau etika (*Attitude*), serta penguasaan keahlian (*Skill*) yang secara seimbang memadukan kecakapan teknis (*hard skills*) dan kemampuan interpersonal (*soft skills*).

* **Kerangka Penyelesaian Masalah**
  Diperkenalkan juga metode dalam mengatasi tantangan proyek, yang harus dimulai dari tahapan mengenali akar permasalahan (Identifikasi masalah), melakukan kajian mendalam terkait isu tersebut (Analisis), merancang jalan keluar yang paling efektif (Rumuskan solusi), hingga proses memaparkan hasil akhirnya kepada audiens atau pemangku kepentingan (Presentasikan).

* **Prosedur Kampus Merdeka**
  Dijelaskan pula panduan untuk berpartisipasi dalam program ini. Alur yang harus diikuti meliputi: memastikan validitas data di PDDikti, membuat akun, memilih program yang sesuai, mengikuti tahapan daftar dan seleksi, hingga akhirnya menjalani program tersebut agar dapat dikonversi menjadi SKS.

* **Penggunaan AI (Prompt Engineering)**
  Panduan memberikan instruksi yang sangat spesifik kepada model AI. Dengan menyertakan peran (*Role*), tugas (*Task*), konteks (*Context*), dan format (*Format*) yang jelas, kita bisa mendapatkan hasil pemrograman yang presisi dan sesuai dengan standar kebutuhan.

* **Version Control (Git & GitHub)**
  Pemaparan mengenai penggunaan Git untuk merekam jejak perubahan kode di komputer lokal, serta GitHub sebagai wadah *online* untuk menyimpan *repository* dan sarana kolaborasi tim. Konsep ini mencakup siklus dari direktori kerja (*Working Directory*), tahapan penyiapan (*Staging Area*), hingga penyimpanan data secara permanen di *Repository*.
